# data30.json 형식 (하루 30곡 입력용)

맥미니에서 하루 30곡을 넣을 때 쓰는 `work/data30.json`의 곡 하나 형식입니다.
기존 항목(제목·아티스트·Key·BPM·링크 등)은 그대로 두고, **곡 분류 항목**을 함께 채웁니다.
분류 항목은 모두 선택이며, 모르는 값은 빼거나 빈 값으로 두면 됩니다.

```json
[
  {
    "title": "은혜",
    "artist": "손경민",
    "key": "G",
    "bpm": 76,
    "capo": 0,
    "youtubeUrl": "https://www.youtube.com/watch?v=...",
    "mrUrl": "",
    "sheetImageUrl": "",
    "sheetPdfUrl": "",
    "structure": "Intro - V1 - C - V2 - C - B - C",
    "notes": "",

    "tempo": "느림",
    "timeSignature": "4/4",
    "durationMin": 5,
    "target": "하나님",
    "traits": ["고백", "감사"],
    "themes": ["은혜", "감사"],
    "hymnNumber": "",
    "scripture": "고린도전서 15장 10절",
    "lyricist": "손경민",
    "composer": "손경민"
  }
]
```

## 항목별 규칙

| 항목 | 값 | 규칙 |
|---|---|---|
| `tempo` | `느림` · `보통` · `빠름` | 비우면 BPM으로 자동 (80 미만 느림, 80~110 보통, 110 초과 빠름). 이 셋 외의 값은 버려짐 |
| `timeSignature` | `4/4` · `3/4` · `6/8` · `12/8` · `2/4` | 10자까지 |
| `durationMin` | 숫자(분) | 0~60. 모르면 0 → 예배 시간 계산에 4분으로 셈 |
| `target` | `하나님` · `예수님` · `성령님` · `사람에 대한 권면` · `공동체` | 하나만. 20자까지 |
| `traits` | 배열 | 추천: 경배, 찬양, 고백, 선포, 감사, 결단, 회개, 기도, 치유·위로, 축복, 파송. 10개까지 |
| `themes` | 배열 (주제 + 절기 함께) | 주제 추천: 예배, 은혜, 사랑, 십자가, 보혈, 부활, 믿음, 소망, 헌신, 선교, 평안, 말씀, 교회, 하나님 나라, 재림<br>절기 추천: 대림절, 성탄절, 송구영신, 신년, 사순절, 종려주일, 고난주간, 부활절, 성령강림절, 맥추감사절, 추수감사절, 어린이주일, 어버이주일, 종교개혁주일<br>20개까지, 한 태그 20자까지. 앞의 `#`는 지움. 쉼표로 쓴 문자열(`"은혜, 감사"`)도 받음 |
| `hymnNumber` | 문자열 | 예: `새찬송가 305장`. 20자까지 |
| `scripture` | 문자열 | 예: `시편 23편`. 100자까지 |
| `lyricist` · `composer` | 문자열 | 60자까지 |

## 주의

- **절기 태그는 정확한 이름으로** 넣어 주세요(위 목록 그대로). 콘티 자동 점검이 "여러 절기 곡이 섞여 있어요"를 판단할 때 이 이름을 씁니다.
- `target`이 `사람에 대한 권면`인 곡만으로 콘티를 짜면 점검 안내가 나오므로, 가사가 회중에게 권하는 내용일 때만 고릅니다.
- 다른 찬양 사이트의 분류 값·키워드를 그대로 옮겨 오지 말고, 가사와 곡을 보고 직접 정합니다.
- 입력은 기존처럼 `POST /api/songs`로 보내면 되고, 서버가 위 규칙대로 정리해서 저장합니다. 이미 넣은 곡에 분류만 더할 때는 `PUT /api/songs/:id`에 분류 항목만 보내면 됩니다.

## Key별 악보 · 여러 장 악보 (선택)

예전처럼 `sheetImageUrl`·`sheetPdfUrl` 한 칸씩 넣어도 그대로 동작합니다. 이렇게 넣은 악보는 앱에서 **‘악보 Key 미확인’**으로 보입니다.
악보에 적힌 Key를 알거나, Key가 다른 악보·여러 장 악보가 있으면 `sheets`로 넣습니다. `sheets`를 넣으면 `sheetImageUrl`·`sheetPdfUrl`은 첫 악보에 맞춰 자동으로 채워집니다.

```json
"sheets": [
  { "key": "G", "label": "", "pages": [
    { "type": "image", "url": "https://.../grace-g-1.jpg" },
    { "type": "image", "url": "https://.../grace-g-2.jpg" }
  ] },
  { "key": "A", "label": "남자키", "pages": [
    { "type": "pdf", "url": "https://.../grace-a.pdf" }
  ] }
]
```

| 항목 | 규칙 |
|---|---|
| `key` | **악보 그림에 실제로 적힌 Key**. 모르면 빈 값(미확인). Db·Eb처럼 써도 C#·D#으로 정리됨 |
| `pages` | 순서대로 넘겨 봄. `type`은 `image` 또는 `pdf`, `url`은 `https://` 주소나 앱에 올린 `/api/sheets/...` |
| 개수 | 악보 10개까지, 악보 하나에 30쪽까지. 쪽이 없는 악보는 저장하지 않음 |

- 다른 사이트의 PDF 주소는 그 사이트가 막으면 앱 안에서 열리지 않고 ‘새 창에서 열기’로만 볼 수 있습니다. 앱 안에서 보고 오프라인 저장까지 하려면 PDF 파일을 앱에서 직접 올려 주세요.
