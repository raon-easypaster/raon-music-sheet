# 저작권 신고(삭제 요청) 처리 — 운영자용

권리자(작사·작곡·편곡자, 출판사, 대리인)는 로그인 없이 **`/copyright`** 화면에서 신고합니다.
앱 첫 화면(로그인), 공유 화면 맨 아래, 사용설명서 저작권 안내에 이 화면으로 가는 링크가 있습니다.

## 1. 운영자 정하기 (한 번만)

Vercel 프로젝트 → Settings → Environment Variables에 다음 값을 넣고 다시 배포합니다.

| 이름 | 값 |
| --- | --- |
| `ADMIN_EMAILS` | 신고를 처리할 계정 이메일. 여러 명이면 쉼표로 구분 (예: `a@church.org,b@church.org`) |

- 이 계정은 **먼저 앱에 가입해 둔 뒤** `ADMIN_EMAILS`에 넣습니다. 앱은 가입할 때 이메일을 확인하지 않으므로, `ADMIN_EMAILS`에 든 이메일로는 새로 가입할 수 없게 막아 두었습니다(남이 먼저 그 이메일로 가입해 운영자가 되는 것을 막기 위해). 넣기 전에 그 이메일 계정이 본인 것인지 확인해 주세요.
- 운영자가 로그인하면 앱 위쪽에 **©️ 신고** 버튼(처리할 신고 수)이 보이고, `/copyright/admin`에서 처리합니다.
- `ADMIN_EMAILS`가 비어 있어도 신고는 접수·저장됩니다. 다만 처리 화면은 아무도 열 수 없습니다.

## 2. 처리 순서

1. **©️ 신고**를 눌러 신고를 엽니다. 신고에 공유 링크가 있으면 그 콘티의 곡과 쪽별 악보 파일이 함께 보입니다.
2. 내용을 확인하는 동안 상태를 **확인 중**으로 바꿔 둡니다.
3. 권리 침해가 맞으면 해당 쪽을 체크하고 **고른 악보 차단**을 누릅니다.
   - 파일은 **지우지 않고** 앱에서 보여 주지만 않습니다. 팀 화면에는 "저작권자의 요청으로 차단된 악보입니다"가 나옵니다.
   - 차단은 서버에는 바로, 브라우저·CDN 저장본까지는 **하루 안에** 모든 화면에 반영됩니다. 기기에 오프라인으로 저장해 둔 사본도 그 기기가 인터넷에 연결돼 악보를 열 때 지워집니다.
   - 다른 사이트 주소로 넣은 악보는 앱이 보관하지 않으므로 차단할 수 없습니다. 이때는 **공유 링크 잠그기**(팀원 전용으로 바꾸고 공유 비밀번호 해제)를 쓰고, 신고자에게 원래 사이트에도 알리도록 안내합니다.
4. 신고자에게 이메일로 결과를 알리고, 상태를 **처리 끝**(또는 **반려**)으로 바꾼 뒤 메모(답변한 날짜·근거)를 남깁니다.
5. 신고가 잘못됐으면 **차단 풀기**로 되돌립니다. 파일이 그대로 다시 보입니다.

## 3. 악보 파일 접근 제한 (참고)

앱에 올린 악보 파일(`/api/sheets/…`)은 볼 권한이 있는 사람에게만 나갑니다: 그 파일을 쓰는 곡의 팀원(개인 곡은 본인), 올린 사람, 그 곡이 든 콘티를 공유 링크로 연 기기(열린 링크 또는 공유 비밀번호로 연 경우), 운영자.
`<img>`는 로그인 헤더를 붙일 수 없으므로 `/api/sheets` 경로에만 쓰는 HttpOnly 쿠키(`raon_sv` 로그인, `raon_ss` 공유 링크)로 확인합니다. 공유 링크 쿠키는 받을 때의 링크 상태(열림·공유 비밀번호)에 묶여 있어, 링크를 잠그거나 비밀번호를 바꾸면 예전 쿠키는 통하지 않습니다. 이 쿠키는 악보 파일에만 쓰이고 로그인 대신 쓸 수 없습니다. 곡에는 내가(팀 곡이면 같은 팀 사람이) 올린 파일이나 내가 볼 수 있는 곡에 이미 든 파일만 넣을 수 있어, 남의 파일 주소를 넣어 볼 권한을 얻을 수 없습니다. 권한을 사람마다 확인하므로 Vercel CDN에는 저장하지 않고(브라우저에만 1시간), 그만큼 악보를 열 때마다 구글 Apps Script를 부릅니다.

## 4. 저장되는 정보

- 신고: 이름, 이메일, 신고자 구분, 저작물, 위치·내용, 처리 상태·메모, 처리한 운영자. 남용을 막기 위해 접속 주소는 원문이 아닌 암호화된 값으로만 남깁니다(한 곳에서 1시간에 5건까지).
- 차단 목록: 파일 번호, 연결된 신고, 차단한 운영자.
