RAON music sheet

찬양팀 악보 & 콘티 관리 앱 사용 가이드

raon-music-sheet.vercel.app
주요 기능
🎵
악보 관리
찬양곡 악보를 등록하고 조(Key)·빠르기(BPM) 정보 관리
📋
콘티 작성
주일 예배 콘티를 만들고 곡 순서를 드래그로 정렬
🔗
공개 공유
로그인 없이도 볼 수 있는 공유 링크 생성
👥
팀 관리
찬양팀 멤버 정보와 역할 관리
시작하기
1
앱 접속
아래 주소로 접속합니다.
raon-music-sheet.vercel.app
2
회원가입
이메일 주소와 비밀번호(6자 이상)를 입력하고 회원가입 버튼을 누릅니다.
이미 가입했다면 "이미 계정이 있어요 → 로그인"을 눌러 로그인합니다.
3
대시보드 입장
로그인 후 곡 목록 · 콘티 · 팀 세 탭이 보입니다. 탭을 눌러 원하는 메뉴로 이동합니다.
악보 등록
1
곡 목록 탭 선택
상단 탭에서 곡 목록을 누릅니다.
2
곡 정보 입력
곡 제목 (필수), 아티스트, Key (예: G, Am), BPM을 입력합니다.
3
악보 파일 또는 링크 등록
PDF 악보를 업로드하거나 YouTube·악보 URL을 붙여넣고 등록을 누릅니다.
🔍 곡 제목 입력 후 구글 버튼을 누르면 "곡명 찬양 악보"로 구글 검색이 바로 열립니다.
💡 곡 제목을 클릭하면 악보 상세 보기(PDF·동영상)가 열립니다.
콘티 작성
1
콘티 탭 선택 후 새 콘티 만들기
상단 탭에서 콘티를 누르고, 콘티 이름을 입력 후 만들기를 누릅니다.
예: "2026년 9월 첫째주 주일 예배"
2
곡 추가
콘티를 선택한 뒤 곡 추가 버튼을 누르면 등록된 곡 목록에서 선택할 수 있습니다.
3
순서 변경
곡 옆의 ⠿ 핸들을 잡고 드래그하면 곡 순서를 바꿀 수 있습니다. 변경된 순서는 자동 저장됩니다.
콘티 공유 & 실시간 동기화
1
공유 링크 생성
콘티 상세 화면에서 🔗 공유 링크 버튼을 누르고 링크를 복사합니다.
2
링크 전달
카카오톡·문자로 팀원에게 전달합니다. 로그인 없이 바로 열람 가능합니다.
3
공유 화면 구성
링크를 열면 왼쪽에 곡 목록, 오른쪽에 현재 곡의 악보·영상이 표시됩니다.
왼쪽 곡 이름을 누르면 해당 곡의 악보로 화면이 전환됩니다.
4
실시간 동기화
한 사람이 곡을 클릭하면 링크를 열고 있는 모든 사람의 화면이 같이 전환됩니다.
예배 인도자가 곡을 넘기면 팀원 화면도 자동으로 바뀝니다.
✅ 공유 링크를 받은 사람은 로그인 없이 콘티·악보를 보고 함께 화면 전환을 할 수 있습니다.
📡 화면은 3초마다 자동 동기화됩니다. 인도자가 곡을 바꾸면 최대 3초 내에 모든 화면이 갱신됩니다.
팀 관리
1
팀 탭 선택
상단 탭에서 팀을 누릅니다.
2
멤버 추가
이름과 역할(보컬, 기타, 드럼 등)을 입력해 팀원을 추가합니다.
비밀번호 변경
1
상단 "비밀번호 변경" 버튼 클릭
로그인 후 화면 오른쪽 상단 비밀번호 변경 버튼을 누릅니다.
2
현재·새 비밀번호 입력 후 변경
현재 비밀번호를 확인한 뒤 새 비밀번호(6자 이상)를 두 번 입력하고 변경을 누릅니다.
🔑 비밀번호를 분실한 경우 관리자에게 문의하면 계정을 초기화해드립니다.
